Trust

Built so the system can be checked, not just trusted.

What protects the data, what limits the AI, and an honest account of what has and has not been tested.

Each company sees only its own data

Isolation is enforced inside the database itself, so a bug in the application cannot read across companies. People also see only the requests assigned to them.

A person approves every AI result

The agents suggest. Reviewers decide. Nothing is approved automatically.

AI use is switched off by default

An administrator turns on AI processing for the company. Sending content to an outside model provider is a separate, second switch. Without a model the agents still work, using deterministic rules.

Spending and requests are capped

Outside AI calls are limited per file, per prompt and per day, and an administrator sets the daily limit or turns them off entirely. Uploads and actions are rate-limited.

AI answers are checked against the file

A model's reading of a spreadsheet is verified against the actual data before anyone sees it, and a made-up answer is discarded and noted.

A tamper-evident audit log

Every action is recorded with the one before it folded in, so editing history breaks the chain at the exact entry. Export the log and verify it yourself with nothing but a hash function.

Hostile files stop at the door

Files are checked by content. Disguised programs, scripts, oversized archives and empty files are refused. Production setups require a real virus scanner.

Sign-in through your company

Production uses single sign-on from your identity provider. Accounts are never created by signing in, and signing out ends the session on every device.

Where it stands

An honest status.

Done

  • A structured security review with fixes and automated tests
  • Fuzz testing of inputs, and tests for double-submits and races
  • Accessibility checks on every screen in light and dark mode

Not done yet

  • An external penetration test
  • SOC 2 or similar certification
  • Sign-in tested against a real identity provider (only a mock so far)
  • Use with real tax data
