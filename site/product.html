Product

Four agents, each with one job, and a person at the end.

Agents work on the files in a request, one building on the last. None of them can approve anything.

ExtractionReads the tables
ValidationChecks the numbers
DocumentsReads letters and PDFs
ReconciliationCompares across files
A personApproves or rejects

Extraction

Finds the table, whatever the layout.

Opens a spreadsheet, works out which column is which, and turns it into clean data.

Reads

Excel and CSV trial balances, including headers in several languages and tables stacked in one sheet.

Checks

Every number it reads. Any it cannot read is flagged, never guessed.

You see

The mapping it chose (for example Soll → Debit), the rows read, and whether an AI model was used at all.

Example

Soll / Haben → Debit / Credit

Validation

Eleven checks before a human looks.

Runs a fixed set of accounting checks on the extracted data and points at the exact rows.

Reads

The data the extraction agent produced.

Checks

Totals that do not balance, duplicate accounts, flipped signs, missing periods and more.

You see

A list of findings, each tied to the row it came from, with a severity.

Example

debits ≠ credits · account 4000 appears twice

Documents

Reads letters and PDFs, and quotes the source.

Pulls the key facts out of confirmations and supporting letters.

Reads

Word, PDF and text files.

Checks

That every fact it reports can be found in the document itself.

You see

Dates, parties and amounts, with the page where each one was found.

Example

"as of 31 December 2025" · p. 2

Reconciliation

Compares what different files say.

Sets a trial balance against the letters in the same request.

Reads

The results of the other agents, within one request.

Checks

Amounts that do not match, directions that flip, and currencies that disagree.

You see

A finding that says what differs, by how much, and what to check.

Example

TB: CAD 410,000 · letter: USD 410,000

What you see on screen

Every result comes with its working.

A reviewer can open "How it was produced" on any result to see whether a model was used, how many calls it made, and what it was checked against.
