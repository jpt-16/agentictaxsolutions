FAQ

Plain answers to the obvious questions.

If something is not covered here, it is probably not decided yet.

What is Pelloria, in plain terms?

Software for corporate tax teams that handles the data-gathering step. A tax manager asks each entity for files, AI agents read and check them, and a reviewer approves every result.

Who is it for?

Tax teams at companies with several legal entities, usually in more than one country, that collect trial balances, confirmations and supporting documents every quarter.

Does it calculate tax or give tax advice?

No. It prepares and checks the data that tax calculations depend on. It does not compute tax, build a provision, file returns or advise anyone.

Does it replace our provision or compliance software?

No. It sits before them, so the data going into those tools has already been collected and checked.

Does the AI make decisions?

No. Agents suggest and flag. A person approves, edits or rejects every result, and nothing is final without that.

Is my data sent to an AI company?

Only if your administrator allows it. AI processing is off by default, and sending content to an outside model provider is a separate switch. Without a model, the agents still work using fixed rules.

Which files and languages does it handle?

Excel, CSV, PDF, Word, text and images. It matches column headers in several languages, including German, and tracks the currency on every result.

How are mistakes caught?

Validation runs eleven accounting checks, reconciliation compares files against each other, and the system flags any number it cannot read instead of guessing. Then a person reviews the result.

Can I see how a result was produced?

Yes. Every result has a "How it was produced" view showing whether a model was used, how many calls it made, and what it was checked against.

Is it ready to use?

Not yet with real tax data. It is a working prototype with a completed security review, but without an external penetration test or certification.
